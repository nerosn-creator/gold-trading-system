Telegram 機器人連線資訊
如何取得 Bot Token 與 Chat ID？
  1. 在 Telegram 搜尋 @BotFather，發送 /newbot，依照指示設定名稱與帳號，即可獲得 HTTP API Token。
  2. 點擊 BotFather 給的連結，在 Telegram 搜尋您的機器人名稱並點擊 Start 開啟對話（務必先點 Start，機器人才有權限推播訊息給您！）。
  3. 在 Telegram 搜尋 @userinfobot，發送任意訊息即可看到您的 Id，該數字即為您的 Chat ID。
  4. 若要發送到群組，將機器人邀請加入群組並給予發言權限，Chat ID 填入該群組 ID（通常為負數）。
